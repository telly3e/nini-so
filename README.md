# 嗖嗖 Siu

一个纯静态浏览器主页，包含翻页时钟、搜索引擎切换、搜索建议和自动天气。

## 本地运行

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 [本地主页](http://127.0.0.1:8765/)。无需安装前端依赖或构建，部署时将静态文件上传至支持 HTTPS 的托管服务即可。文本文件统一使用 UTF-8。

## 功能

- 搜索支持百度、Google、Bing、DuckDuckGo，并在本机记住选中的引擎。
- 百度、Google、Bing 支持搜索建议；支持方向键选择、回车搜索和清空输入。
- 时钟跟随系统深浅色变化，搜索框聚焦时收起天气。
- 天气显示地点、天气状况、温度、风速和湿度；默认隐藏位置设置及定位来源说明。

## 天气定位

自动模式并发请求 IPIP、ipapi.co 和 FreeIPAPI，默认优先采用中国大陆（CN）定位结果：

1. 国内有效结果先返回，立即采用。
2. 国外结果先返回，最多再等 1.2 秒；国内结果仍未准备好，则采用第一个有效的国外结果。
3. 所有请求已结束时，不再额外等待。结果确定后取消剩余请求。

国内路径由 IPIP 提供国家、省份和城市，再用 Open-Meteo Geocoding 转换为城市中心坐标。转换时严格匹配国家、省份和城市，匹配不唯一则回退。不会将 IPIP 返回的公网 IP 转交其他服务。

竞速比较的是完整有效坐标的返回时间，包含城市转坐标耗时。每次网络请求超时为 6.5 秒，国内路径包含两次顺序请求。天气按坐标缓存 10 分钟，切换位置不会误用旧城市的天气，语言跟随浏览器。

### 代理分流

使用 `geosite:cn` / `geoip:cn` 直连时，建议确认实际请求域名 `myip.ipip.net` 命中 DIRECT；是否命中取决于规则库和规则顺序，必要时添加该域名的明确直连规则。网页不能强制绕过代理，IP 地点也只是出口城市估算。

IPIP 是免费服务，不保证服务质量；其文本格式、跨域支持及其他接口的可用性可能变化。天气由 [Open-Meteo](https://open-meteo.com/) 提供，城市数据来自 [GeoNames](https://www.geonames.org/)。

### 可选位置设置

设置功能保留在组件中，当前默认隐藏。需要恢复入口和定位来源说明时，在 `index.html` 中添加属性：

```html
<geo-weather-bar show-settings></geo-weather-bar>
```

展开“天气位置设置”后可使用：

- **最快有效结果**：关闭国内优先，严格采用最先返回的有效坐标。
- **固定城市**：搜索并确认省份、国家后保存，下次打开沿用。
- **设备位置**：点击后申请定位授权，需要 HTTPS 或 localhost；位置仅用于当前页面，不保存为默认城市。天气缓存仍包含取三位小数的坐标键。
- **自动 IP 定位**：清除固定城市，恢复自动定位。
- **刷新**：跳过天气缓存重新获取。

隐藏设置不会清除之前保存的城市或策略。需要修改已有偏好时，可临时恢复设置入口。

如有自建国内定位服务，可用 `domestic-geo-url` 属性添加并发源。接口需支持 HTTPS 和主页的跨域访问，返回以下格式；服务端密钥不能写入静态页面：

```json
{"latitude":31.3,"longitude":120.6,"countryCode":"CN","country":"中国","region":"江苏","city":"苏州"}
```

服务端应从可信请求来源识别访问者 IP，避免误用服务端自身出口。

## 代码结构与维护

- `js/weather-service.js`：定位源、竞速选择、城市查询、数据校验和超时控制。
- `js/geo-weather-bar.js`：天气展示、可选位置设置和缓存。
- `js/search-bar.js`：引擎切换、建议请求及键盘交互。
- `js/local-storage.js`：配置校验与存储异常回退。
- `js/global.js`：搜索聚焦效果和系统主题同步。
- `tests/`：使用 Node.js 内置测试工具，无第三方测试依赖。

搜索建议使用纯文本渲染；请求按组件、引擎和关键词隔离，并清理超时及过期回调。缓存最多保留 100 条。组件移除时清理事件监听器。损坏的配置或不可用的存储不会阻断搜索，非法引擎回退至百度。

搜索建议仍沿用提供商的 JSONP 接口，因此仍需信任提供商返回的脚本。纯文本渲染解决的是建议文本的 HTML 注入问题。

```sh
node --test tests/*.test.cjs
```

本地浏览器已验证自动天气、固定城市与重载保持、切回自动定位、百度和 Bing 建议、清空输入及引擎记忆。设备授权成功及真实操作系统主题切换仍需在目标设备验证。

接口文档：[IPIP](https://www.ipip.net/myip.html)、[Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api)、[FreeIPAPI](https://freeipapi.com/)、[ipapi.co](https://ipapi.co/api/)。
